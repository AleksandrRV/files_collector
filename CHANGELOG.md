# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Fixed

- **B9.** Счётчики, оценка размера и токенов и дерево совпадают с отчётом: содержимое `Full`/`Signatures`-файлов проверяется в фоне (`IFileContentProbe`), бинарные файлы учитываются как `Listed / binary_file`. Дерево показывает режим из плана и помечает решения фильтров источником `Filter` с причиной; фильтр `Excluded only` находит и файлы, исключённые фильтрами.
- **B10.** Экспорт пресета содержит всё текущее состояние, включая несохранённые правила дерева.
- **B11.** `defaultMode` пресета применяется к файлам без правил и настраивается на вкладке `Formats` (`Default mode`).
- **B12.** `Follow reparse points` работает в inventory и в дереве; циклы ссылок завершаются.
- **B13.** Переключение, удаление, отмена изменений и импорт пресета сначала спрашивают о несохранённом префиксе, если префикс меняется; отмена оставляет всё как было.
- **B15.** `Rename` пресета и prefix preset меняет только имя и больше не сохраняет другие изменения.
- **B16.** Ошибки валидации имени prefix preset показываются пользователю; вместо stack trace показывается сообщение (подробности — в логе).
- **B17.** Обновление inventory: у каждого запуска свой токен отмены и номер поколения; устаревший запуск не публикует результат и не сбрасывает индикатор. Таймер, watcher и смена корня больше не вызывают команду в обход её состояния.

- **B4.** Открытие удалённого отчёта из History или через `Open report` больше не роняет приложение: запись убирается из списка, ошибки оболочки Windows показываются в диалоге.
- **B5.** Импорт пресета проверяет файл целиком (`PresetImportValidator`) и сообщает обо всех проблемах с JSON-путями; `null`, неверные типы, числа вне диапазона, недопустимые пути и расширения больше не вызывают `NullReferenceException`. Имя с запрещёнными символами больше не зацикливает подбор уникального имени. Экспорт ограничивает значения диапазонами импорта, поэтому любой экспорт импортируется обратно.
- **B6.** Необработанное исключение UI больше не закрывает приложение; закрытие только при неустранимых ошибках или серии ошибок (`UnhandledExceptionPolicy`).
- **B7.** Закрытие окна и завершение сеанса Windows спрашивают о несохранённых изменениях пресета и prefix preset и о выполняющейся генерации отчёта.

- **B1.** Содержимое скрытых и системных папок наследует атрибуты Hidden/System: при выключенном `Include hidden files` файлы внутри скрытой папки (например, `.git` в Git for Windows) больше не попадают в отчёт.
- **B1.** Служебные данные VCS (`.git`, `.svn`, `.hg`, `.bzr`, включая файл `.git` у submodule) стали системным исключением: inventory их не обходит, дерево показывает `System` / `Excluded`, manifest — причину `vcs_metadata`. Фильтр `.gitignore` игнорирует `.git` неявно, как Git.
- **B2.** Новый детектор текста и бинарных данных: zlib-объекты Git, архивы и случайные байты больше не выводятся как текст в Windows-1251. UTF-16 с BOM теперь распознаётся как текст (раньше считался бинарным из-за нулевых байтов).
- **B3.** Отчёт и manifest используют только `LF`: служебные строки, prefix, содержимое файлов и вывод signature extractors.
- **B8.** Выбор папки приложения или корня без inventory сбрасывает план предыдущего корня; `Create report` больше не может записать файлы старого корня под именем нового.

### Changed

- Схема inventory cache дополнена полем `FollowsReparsePoints`; `IFileInventoryStore.Refresh` принимает `followReparsePoints`, `MainWindowViewModel` — `IFileContentProbe`.
- `RuleSet.Resolve` и `CollectionPlanner.CreatePlan` принимают режим по умолчанию; правило расширения сохраняется, только если отличается от режима по умолчанию.

- Формат импорта пресета стал строже: неизвестные и повторяющиеся поля, числовые значения режимов и `null` (кроме `gitIgnorePath`) теперь ошибки. Допускаются комментарии и завершающие запятые. Добавлена JSON Schema `docs/schemas/files-collector-preset-v1.schema.json`.

- Схема inventory cache повышена до версии `2`; cache версии `1` при открытии отбрасывается и строится заново.
- В manifest добавлены описания кодов `vcs_metadata`, `binary_extension`, `file_unavailable`, `content_omitted`, `signature_syntax_warning`, `signature_extraction_failed`.

### Tests

- `PlanConsistencyTests`, `SampledFileContentProbeTests`, `ReparsePointInventoryTests` (ссылки; тесты пропускаются без права создавать symlink), `UiConsistencyTests` (дерево и фильтры, режим по умолчанию, экспорт, переименование, префикс при переключении, ошибки имени префикса, обновление inventory при `Follow reparse points`).

- Тесты валидатора импорта, синхронизации JSON Schema с кодом, политики необработанных исключений, открытия удалённых отчётов, импорта через ViewModel и подтверждения закрытия. Общая обвязка ViewModel вынесена в `ViewModelTestHost`.

- Golden-тест отчёта (`Golden/report.golden.md`) на фикстуре с `.git`, submodule-файлом `.git`, скрытой папкой, бинарными файлами, zlib-потоком, CRLF, Windows-1251 и UTF-16. Эталон обновляется запуском тестов с `FILES_COLLECTOR_UPDATE_GOLDEN=1`.
- Тесты детектора текста, системных исключений VCS, наследования Hidden, версии cache и сброса плана при смене Scan Root.
